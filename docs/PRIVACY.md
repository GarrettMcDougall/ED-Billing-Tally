# Privacy

## Data handling

The calculator runs entirely in the browser. It does not send shift data to a server and does not include analytics, telemetry, advertising, cookies, or user accounts.

## Local storage

Active shifts, completed shift history, settings, and recent/pinned-code preferences are stored using browser LocalStorage on the current device and browser profile. Data is not synchronized automatically between devices.

## Patient information

The workflow is designed for anonymous cases. **Do not enter names, health-card numbers, dates of birth, medical-record numbers, or other patient identifiers.**

## Backups

JSON backups and CSV exports are created only when the user requests them. The user controls where those files are stored and shared.
