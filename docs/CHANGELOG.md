# Changelog

## 1.11.0

- Added automatic update checks when the installed app launches, resumes, or reconnects to the internet.
- Added a build fingerprint check across `index.html`, `manifest.webmanifest`, and `sw.js`.
- Added immediate service-worker activation and controlled app reload after a new version is ready.
- Changed same-origin app resources to network-first fetching with offline cache fallback.
- Preserved LocalStorage shift history, settings, pins, and active-shift data during updates.

## 1.10.0

- Removed the real-time 120-minute blocking validation for reassessment entry.
- Preserved the standard **Reassessment** action and **Next time-block reassessment** workflow.
- Added hold-to-pin and hold-to-unpin gestures for quick codes.
- Added a persistent **Undo last code** button.
- Added swipe-left deletion to ledger rows.
- Updated PWA cache version and complete repository documentation.

## 1.9.0

- Added PWA manifest, service worker, install icons, and offline app-shell caching.

## 1.8.0

- Added a sticky Settings header.
- Added pinned-code search and usage-based recommendations.

## 1.7.0

- Improved text contrast across all themes.

## 1.6.0

- Added Dark Tactical, Neon Clinical, and Minimal Light themes.
