# Contributing

1. Fork the repository and create a focused feature branch.
2. Preserve the anonymous, offline-first workflow.
3. Do not add analytics, trackers, external fonts, or remote runtime dependencies.
4. Document billing-rule changes with the applicable authoritative source.
5. Test mobile layouts, all themes, offline loading, backup/export, and existing calculation workflows.
6. Submit a pull request describing the change, testing performed, and any billing assumptions.
